# 🐞 BUG-001: API de Pagamento PIX aceita valor zerado (`amount: 0.00`)

* **ID no Jira:** `[PAY-302]`
* **Severidade:** Alta
* **Prioridade:** Alta
* **Componente:** API de Pagamentos / PIX

---

## 📋 Descrição
A API `POST /api/payments/pix` permite criar transações com `amount = 0.00`, violando a regra de negócio do produto que exige valores estritamente positivos.

---

## 🔄 Passos para Reproduzir
1. Configurar requisição `POST` no Postman para o endpoint `/api/payments/pix`.
2. Adicionar o cabeçalho `Content-Type: application/json`.
3. Enviar o seguinte Body JSON:
   ```json
   {
     "amount": 0.00,
     "payer_email": "cliente@email.com"
   }
